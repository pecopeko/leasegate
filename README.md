# LEASEGATE（リース門）

**新リース会計基準（企業会計基準第34号 / 2027年4月強制適用・IFRS 16整合：使用権資産・リース負債の現在価値オンバランス算定・短期12か月/少額300万円免除判定・組込リース識別・初年度利息＆減価償却計算）ブラウザ完結ローカル監査ツール**

- 賃料・契約期間・追加借入利子率（IBR）・資産購入価額・賃貸/業務委託契約条項を外部サーバーへ **一切送信しません**（ネットワーク通信 `0` 回）。
- 全借手リースのオンバランス対象判定・**割引現在価値（PV）**・初年度支払利息および定額減価償却費を即時算出し、**『新リース会計基準（企業会計基準第34号）オンバランス影響試算・監査書（Markdown）』** を生成します。
